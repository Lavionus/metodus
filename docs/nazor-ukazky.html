Názorné prvky Metodusu

Knihovna nazor.js – stejný jev se na celém webu kreslí stejně. Stránka slouží k vývoji a kontrole vzhledu.

Zlomek: koláč, proužek, osa

Nazor.kolac(4, 3) · Nazor.prouzek(4, 3) · Nazor.zlomekNaOse(3, 4)

Číselná osa

Nazor.osa({ od: -5, do: 5, body: [...], skok: { z: -2, na: 3, popis: '+5' } })

Nazor.osa({ od: 2, do: 3, krok: 0.1, body: [{ hodnota: 2.35 }] })

Procenta

Nazor.procenta(36, 120, { jednotka: 'Kč' })

Věta s větnými členy

Nazor.veta([['Malý','privlastek'],['chlapec','podmet'],['kreslí','prisudek'],['obrázek','predmet'],['doma','urceni']], { znacky: true })

Časová osa

Nazor.casovaOsa(udalosti, { pruhy: [{ id: 'cr', nazev: 'Česko' }, { id: 'svet', nazev: 'Svět' }] })

Mapa (mapy.js)
