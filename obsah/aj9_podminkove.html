🔀 Podmínkové věty

Pro 9. ročník: nultý, první a druhý kondicionál – reálná i nereálná podmínka.

📖 Výklad: Podmínkové věty (kondicionály)

Podmínková věta má dvě části: podmínku s if a důsledek. Který typ použiješ, záleží na tom, jak skutečná podmínka je: platí vždy, může se opravdu stát, nebo si ji jen představuješ? Typ poznáš podle slovesných tvarů v obou částech.

0. – vždy platí

if + přítomný čas, přítomný čas
If you heat water to 100 °C, it boils.
Obecné pravdy a zákonitosti; if tu znamená skoro „kdykoli“.

1. – reálná budoucnost

if + přítomný čas, will + základní tvar
If it rains tomorrow, we will stay at home.
Může se to opravdu stát.

2. – nereálné, představa

if + minulý čas, would + základní tvar
If I won a million, I would travel around the world.
Minulý tvar tu neznamená minulost, ale „není to tak“ nebo „asi se to nestane“.

Nejčastější chyba: dát will do části s if – If it will rain… ✗. Budoucnost tam vyjadřuje přítomný čas: If it rains…. Stejně tak would patří jen do důsledku.

U slovesa be se ve 2. kondicionálu užívá were pro všechny osoby: If I were you, I would apologise. (Americky apologize; v hovoru slyšíš i If I was…) Když věta začíná podmínkou, odděl obě části čárkou.

0.: přítomný + přítomný. 1.: přítomný + will. 2.: minulý + would. Ve větě s if nikdy will.
📘 Ukázka: který kondicionál?

O který kondicionál jde: If we lived by the sea, we would swim every day.

  1. Podívám se na sloveso v části s if: lived – minulý tvar.
  2. V důsledku je would swim – would + základní tvar.
  3. Minulý tvar + would = 2. kondicionál.
  4. Ověřím význam: u moře nebydlíme, je to jen představa – sedí to na nereálnou podmínku.

✅ 2. kondicionál – nereálná situace: Kdybychom bydleli u moře, plavali bychom každý den.

0. If + present, present – obecná pravda 1. If + present, will + infinitiv – reálná budoucnost 2. If + past, would + infinitiv – nereálná či nepravděpodobná situace

Ve větě s if nikdy nepoužíváme will – budoucnost vyjadřuje přítomný čas. Ve druhém kondicionálu se u slovesa be často používá were pro všechny osoby: If I were you…
